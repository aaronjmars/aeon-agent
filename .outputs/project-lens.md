*New Article: GitHub Made Copilot Better By Cutting Twenty-Seven Of Its Tools. Most AI Agent Roadmaps Are Built To Do The Opposite.*

The 2026 research keeps surfacing the same finding — adding tools to an AI agent makes it worse. Tool selection accuracy drops from ~95% to ~71% when the full GitHub MCP server loads; standard setups now eat 72% of context on tool definitions before work starts. Aeon's most underrated design decision is the opposite move: PR #65 on May 28 disabled five scheduled skills in one commit, skills land disabled by default, and notifications are gated to silence. The agent that runs everything is the agent that does nothing well.
