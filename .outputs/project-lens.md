*New Article: The Agent Wars of 2026 Are a Fight Over Whose Computer Runs Your Agent*

Every agent platform that shipped this year — OpenAI Frontier, Amazon's Stateful Runtime in Bedrock, Anthropic's sandboxes, LangSmith — sells the same thing: a runtime your agent lives in but you don't own. Whoever owns the runtime owns the workflow, and a survey this spring found you can't move six months of agent memory off one without rebuilding it from scratch. Aeon sits in the corner nobody's fighting over — it runs as your own GitHub Actions cron with state as git-committed markdown, so "migration" isn't a roadmap item, it's `git clone`. The bet: hosted runtimes win the next year on convenience and lose the one after on exit. ⭐
