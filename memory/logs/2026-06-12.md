### Lesson
- `next build` (Turbopack) is the ONLY check that enforces the `"use server"` "async-functions-only export" rule — `tsc --noEmit` and eslint both pass on a file that breaks the build. When auditing a Next.js App Router repo, run a real build, not just typecheck. A single illegal export in a `"use server"` module cascades to "module has no exports at all" across every importer.
