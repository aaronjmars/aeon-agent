### aaronjmars/minitor — per-column color labels (Jun-04 idea #5, 7th rung on per-column UX axis)
- **Branch**: feat/column-color-labels
- **PR**: https://github.com/aaronjmars/minitor/pull/61
- **Why**: At 10–15 columns per deck, visual scan time becomes the bottleneck. Operators mentally group columns (DeFi/dev/news/social) but had no in-app marker for it — only tab groups (hide/show), collapse (fold to 48px), and pin (reorder). Color is the "at-a-glance" layer the axis was missing.
- **What was built**: 10 files, +611/-5. Migration `drizzle/0008_column_color.sql` adds nullable `text("color")` column. Schema + types + deck-templates updated. `app/actions.ts` gains `COLOR_HEX_RE` + `normalizeColumnColor()` server-side validator (lowercased, 6-hex only — 3-hex shorthand and named CSS colors rejected so stored form is canonical), `updateColumnColor()` server action, `importedColumnSchema` Zod regex, `importDeck` re-validation (drop invalid like webhook SSRF guard, never abort import), `exportDeck` emits when set, `duplicateColumn` inherits color. Store `updateColor()` optimistic action mirrors server normalization. Configure dialog gets "Color label" field with 8 preset swatches (orange/green/blue/purple/pink/yellow/cyan/slate) + Clear button + freeform hex input with live invalid-hex error + disabled-Save guard. Column card renders 10px circular dot next to title in expanded header when color set, and the expanded-header + collapsed-strip top accent gradient uses `column.color ?? type.accent`.
- **Key design decisions**: (1) **Color IS inherited on duplicate; `pinned` is NOT** — color = visual labeling ("what kind of column?"), pin = routing ("primary column?"); (2) Server-authoritative hex regex applied at both `updateColumnColor` and `importDeck` so a tampered export can never smuggle a non-canonical color into the DB; (3) Round-trips through export/import/share-links + snapshots — same DB-backed shape as PR #59's `pinned` because color is a persistence decision about the deck's identity, not view-state; (4) 8 preset swatches + freeform hex covers the realistic operator workflow — custom palettes / auto-color-by-plugin deliberately out of scope (the whole point of color labels is operator intent).
