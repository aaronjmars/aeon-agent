## MiroShark shipped its first public dataset

The headline ship of the window: MiroShark released **8,201 decisions from its social + prediction-market agent simulations** as an open dataset on Hugging Face — the first time the sim layer's raw reasoning traces have shipped publicly. Each row links a post, a quote, a follow, or a YES/NO trade back to what the agent saw and what it reasoned before acting, so you can trace exactly when narrative turned into a position, when sentiment moved a bet, or when a regulator-persona agent started trading like a degen.

Shipped as: `MiroShark/MiroShark` #311 (README link to the HF dataset), `aaronjmars/miroshark-website` #356 (blog post for the release). The announcement tweet (39 likes) framed it as the first-of-its-kind dataset pairing social argument with trading action — an underexplored primitive the team is now building on directly.
