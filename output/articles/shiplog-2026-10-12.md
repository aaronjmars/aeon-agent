## The framework

27 PRs landed on `aeonfun/aeon` this week, split between a CI-reliability pass and a few real feature/hardening ships:

- **Haiku tier moved to Claude Haiku 5.5** ([#1189](https://github.com/aeonfun/aeon/pull/1189)) — shipped the day Anthropic dropped it (10-07), swapped in everywhere aeon pins the haiku tier (dashboard picker, workflow_dispatch choices).
- **CI hardening**: an `apt-get update` hang on a slow mirror was killing read-only skill runs mid-install of bubblewrap — ported the fix from this repo's own [#255](https://github.com/aaronjmars/aeon-agent/pull/255) into the framework ([#1186](https://github.com/aeonfun/aeon/pull/1186)), plus running the harness from a snapshot so a skill that syncs `harness-adapter` can't break its own run ([#1180](https://github.com/aeonfun/aeon/pull/1180)) and dropping `restore-keys` on the npm cache so pin bumps actually install ([#1169](https://github.com/aeonfun/aeon/pull/1169)).
- **Secret tripwire hardened**: the GitHub-token regex in email-sending skills only matched `gh[pousr]_[A-Za-z0-9]{20}` — stateless `ghs_` tokens with underscores slipped the net. One character-class fix ([#1177](https://github.com/aeonfun/aeon/pull/1177)).
- **Biome formatter added for all 4 apps** (cli, dashboard, mcp-server, webhook) — none had one before ([#1193](https://github.com/aeonfun/aeon/pull/1193)).
- **Hosted MCP Connect** got its docs pointer live at `www.aeon.fun/connect/mcp` ([#1192](https://github.com/aeonfun/aeon/pull/1192)), plus two mcp-server fixes (dropped an undefined cron, passed the resolved model like scheduled runs — [#1190](https://github.com/aeonfun/aeon/pull/1190), [#1191](https://github.com/aeonfun/aeon/pull/1191)).
- Plugin-directory cleanup across Claude, OpenAI Codex and (briefly) MiniMax listings ([#1176](https://github.com/aeonfun/aeon/pull/1176), [#1178](https://github.com/aeonfun/aeon/pull/1178), [#1182](https://github.com/aeonfun/aeon/pull/1182), [#1184](https://github.com/aeonfun/aeon/pull/1184), [#1187](https://github.com/aeonfun/aeon/pull/1187), [#1188](https://github.com/aeonfun/aeon/pull/1188)).

**Aeon Connect** (the hosted onboarding flow at aeon.fun/connect, the headline from last week's shiplog) got a smaller polish pass this window: a Lighthouse a11y fix (step-number contrast, footer heading order — [#84](https://github.com/aaronjmars/aeon-connect/pull/84)) and two SEO fixes (canonical link, description length — [#82](https://github.com/aaronjmars/aeon-connect/pull/82), [#83](https://github.com/aaronjmars/aeon-connect/pull/83)).

## Ecosystem — the real story this window

Two external contributors shipped community skill packs and got them merged straight into the framework's own registry (`catalog/skill-packs.json` + `docs/community-skill-packs.md`):

- **Epoch pack** ([#1168](https://github.com/aeonfun/aeon/pull/1168), by [Svector-anu](https://github.com/Svector-anu)) — a full engineering workflow running inside an Aeon instance: `epoch-spec` writes work orders, `epoch-build` opens a PR, `epoch-review` posts a review receipt pinned to the head sha, `epoch-watch` returns a readiness verdict. Lives at [Svector-anu/epoch](https://github.com/Svector-anu/epoch) (MIT, 2 stars, created the same day). Builder @svector_eth launched it on X same window ("your engineer just arrived — introducing epoch v1 — your own unattended software engineer, built on Aeon") and @aeonframework gave the public congrats.
- **bon travail pack** ([#1167](https://github.com/aeonfun/aeon/pull/1167)) — also from Svector-anu — an open-source loop where agents find broken CI and pay humans to fix it. Two skills: `proofwork-loop` sweeps a deployment every 10 minutes and pays/refunds from escrow on Arc against the repo's own CI results; `proofwork-investigate` bisects a repeated failure to the first bad commit. The operator also landed a direct PR into [Svector-anu/bon-travail](https://github.com/Svector-anu/bon-travail) itself (MIT license + a scoping note).

Separately, **19 PRs went out this window adding Aeon to MCP marketplaces, registries, and awesome-lists** — docker/mcp-registry, MoonshotAI/kimi-code, NousResearch/hermes-agent, CognitionAI/devin-marketplace, xai-org/plugin-marketplace, cline/marketplace, Kilo-Org/kilo-marketplace, pathintegral-institute/mcpm.sh, toolsdk-ai/toolsdk-mcp-registry, davila7/claude-code-templates, nanbingxyz/mcpsvr, MobinX/awesome-mcp-list, and two `awesome-remote-mcp-servers` forks. **Three already merged**: [punkpeye/awesome-remote-mcp-servers#1427](https://github.com/punkpeye/awesome-remote-mcp-servers/pull/1427), [mcpHQ/awesome-mcp-servers#166](https://github.com/mcpHQ/awesome-mcp-servers/pull/166), and [swiss-knife-xyz/swiss-knife#184](https://github.com/swiss-knife-xyz/swiss-knife/pull/184). One of the merges in the pipe traces back organically — a community member (@apoorveth) tweeted "added @aeonframework to [an MCP list]" independent of this push. That's the fork-ability story from STRATEGY's priority #3 (lower the barrier) turning into actual discoverability surface across every agent harness's plugin directory.
