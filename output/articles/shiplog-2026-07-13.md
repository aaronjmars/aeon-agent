# aeon v0.1 is live — stable release, README overhaul, and a tier-list cameo

**Window:** 2026-07-09 → 2026-07-13  
**By the numbers:** 47 PRs across 5 repos · 29 commits on aaronjmars/aeon · 0 external-security PRs · aeon 574 ⭐ (+3) · MiroShark 1360 ⭐ (+3)

---

## The headline: v0.1.0 stable

aeon tagged `v0.1.0` on Jul 10. After ~70 partners running pre-release builds and feeding back friction, this is the first version the team is calling stable. What changed:

- **Grok harness support** — xAI's models now run natively alongside Claude; X login via your X subscription is live, so you can run agents for free using the X sub.
- **Channel improvements** — Telegram Instant mode, new commands, email added.
- **OKF (Open Knowledge Format)** — Google's open standard wired into skill outputs; memory and articles now carry machine-readable metadata.
- **Attestation** — skills can now prove what they ran, on-chain or off-chain.
- **Langfuse observability** — opt-in trace and span logging for every skill run.
- **Codebase simplification** — fewer skills, fewer dependencies, cleaner surface.

The v0.1 thread on `@aeonframework` landed 69 likes, 11 RTs, 7 replies. The repo link got another round of shares.

Both public automation instances (`aeon-agent`, `miroshark-aeon`) were migrated onto the v0.1.0 template on the same day (#143, #102).

## README overhaul (10 PRs, Jul 9)

Ten consecutive PRs trimmed the README from 733 → 596 lines and rewrote most of the top half:

- Sharper hero + "Proof of work" section showing real skill output (#701)
- Authentication + Notifications setup rewritten with Grok and clickable links (#705)
- Advanced section trimmed, internals relocated to `docs/` (#700, #708)
- Pack table aligned, self-healing image dropped, community packs steered toward the registry (#703)
- Stale references refreshed — catalog move, webhook secret, skill count (#699)
- Gateway/auth story deduped (was told 3–4× in the same README) (#706)

The through-line: the README is a fork decision — every line that slows someone down deciding whether to clone is a lost instance. Nine docs PRs and one model-backstop fix (aligning default to `sonnet-4-6`, #698).

---

## Operational hardening

Three PRs tighten the run loop:

- **Retire postprocess; run irreversible sends in-run** (#695, #707) — deploys, token transfers, and other side-effecting actions now fire via `./secretcurl` inside the skill run rather than a detached post-run step. A failure surfaces in the run, not silently.
- **Transient skill writes → `/tmp`** (#713) — skills that generate scratch files no longer pollute the repo root.
- **Surface swallowed errors in MCP CLI + outputs route** (#716) — errors that were eaten silently now propagate to the caller.

Plus the **health scorer fix** (#714, applied across all three automation repos): the scorer was flagging legitimate no-ops as `empty_output`; it now only fires on genuinely empty final outputs.

## Agent-readiness on the website

`aeon-website` PR #144 added a full agent-readiness / AEO layer:

- `llms.txt` — machine-readable index for language model crawlers
- `agents.md` — capability manifest for agentic discovery
- Trust pages + JSON-LD schema

This is the "agents navigating to aeon" surface: the site now speaks to the crawlers looking for it, not just the humans.

## minitor: SSRF fix, one-click deploy, auth wall

Three meaningful PRs on minitor this window:

- **#100** — biggest: SSRF fix, column caching, resilient integrations, and one-click Docker/Railway hosting in a single PR. The SSRF fix alone is worth flagging — it closes a server-side request forgery vector in the feed-fetch path.
- **#101** — password login page for hosted deployments. Before this, self-hosted minitor was open to anyone with the URL.
- **#98** — three Dependabot security alerts resolved (brace-expansion, @babel/core, esbuild).
- **#102** — Reddit RSS guard, GitHub stars/discussions token guards, Bluesky + Bing columns removed.

minitor is shaping up as a clean, hostable product. The SECURITY.md is still missing (tracked as a P2 flag in heartbeat) — that's the remaining gap.
