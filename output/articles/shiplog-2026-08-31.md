# Aeon shiplog — Aug 24 → 31

Window: 2026-08-24 → 2026-08-31 (since the last run, 7 days). Everything below traces to a PR number, a commit, a measured count, or a linked post.

## The flagship: aeonfun/aeon — 57 PRs merged

The engine room week. The big move: **GLM stopped being a harness and became an LLM gateway** ([#990](https://github.com/aeonfun/aeon/pull/990)) — with tiered model mapping so sonnet/opus/haiku-class requests each route to the right GLM tier ([#998](https://github.com/aeonfun/aeon/pull/998)), and a follow-up pinning reasoning effort to high, var-overridable, still open ([#999](https://github.com/aeonfun/aeon/pull/999)). Earlier in the window the Cursor / Hermes / GLM harnesses landed ([#967](https://github.com/aeonfun/aeon/pull/967)); by Sunday the architecture had already reorganized around them.

Reliability was the theme everywhere else:

- **fail-closed adapters** — the message envelope now fails hard on unparseable adapter output instead of limping along ([#987](https://github.com/aeonfun/aeon/pull/987)), Hermes runs fail on API errors ([#984](https://github.com/aeonfun/aeon/pull/984)), transient xAI search failures retry ([#989](https://github.com/aeonfun/aeon/pull/989))
- **accountability loop** — chained runs correlate uniquely ([#988](https://github.com/aeonfun/aeon/pull/988)), and the repair loop no longer marks an issue resolved when the PR is merely *opened* ([#997](https://github.com/aeonfun/aeon/pull/997)) — a fix to the self-healing loop's own honesty
- **agent UX** — Telegram can reply to a previous skill run ([#995](https://github.com/aeonfun/aeon/pull/995), [#996](https://github.com/aeonfun/aeon/pull/996)), the dashboard's Connect flow copies the gh token into GH_GLOBAL ([#993](https://github.com/aeonfun/aeon/pull/993)) and now requires an exact origin-host match ([#986](https://github.com/aeonfun/aeon/pull/986))
- **ecosystem packs** — three third-party skill packs registered: Spoolis Outcome Gate ([#978](https://github.com/aeonfun/aeon/pull/978)), CultOS ([#974](https://github.com/aeonfun/aeon/pull/974)), Farcaster Pack ([#977](https://github.com/aeonfun/aeon/pull/977)); plus the cortx-reliability skill (x402 endpoint checks, [#954](https://github.com/aeonfun/aeon/pull/954)) and machine-readable vuln-scanner execution evidence ([#968](https://github.com/aeonfun/aeon/pull/968))

Also notable: #968's evidence format, #971's macOS issue-store default-repo fix, and the operator-console plugin prepped for OpenAI submission ([#959](https://github.com/aeonfun/aeon/pull/959)).

## The fleet fought its own outage

The best story of the week isn't a feature. On 08-31 the LLM gateway went down and **7 skills failed at once** — 17 failed runs, zero tokens, $0 cost signatures. The instance's heartbeat diagnosed it as a shared gateway dependency (not per-skill bugs), the fix pinned the Claude harness to the GLM gateway (commit `b054cb0`), and when the pin didn't hold, the evening heartbeat caught the regression and re-escalated with corrections to its own morning report. Public traces the whole way: [incident report](https://github.com/aaronjmars/aeon-agent/blob/main/output/heartbeat-2026-08-31.md), [regression update](https://github.com/aaronjmars/aeon-agent/blob/main/output/heartbeat-2026-08-31-regression.md), status page rewritten twice. Gateway was still flapping as of 20:26 UTC — the honest tail of the story.

Around the incident, aaronjmars/aeon-agent merged 7 PRs: the aeon-update fork sync ([#198](https://github.com/aaronjmars/aeon-agent/pull/198), 25 upstream commits / 84 files), egress-audit hardening ([#194](https://github.com/aaronjmars/aeon-agent/pull/194)), a fleet-hardening backport ([#196](https://github.com/aaronjmars/aeon-agent/pull/196)), an AI_GATEWAY/VERCEL_OIDC allowlist ([#197](https://github.com/aaronjmars/aeon-agent/pull/197)), and swapping a silent `curl|bash` for the foundry-toolchain action in deploy-uni-hook ([#195](https://github.com/aaronjmars/aeon-agent/pull/195)).
