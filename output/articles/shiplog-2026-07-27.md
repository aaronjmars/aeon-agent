## The core: aeonfun/aeon — 18 PRs, 19 commits

This window's headliner is **multi-harness** (#765). Aeon now runs on six agent CLIs — Claude Code, Codex, pi, vibe, kimi, plus Hermes/OpenClaw — dispatched through a single harness-adapter layer. The framework stopped being "Claude Code with skills" and became harness-agnostic. Pick your runtime, the skills and scheduler don't move.

Riding alongside:

- **Claude 5 family** (#775) — Sonnet 5 becomes the default model. The Claude 5 family is the only offered tier now.
- **aeon-doctor** (#761) — a static config-correctness linter that catches misconfigurations before a run fails. First self-diagnostic tool in the stack.
- **Grok OAuth fix** (#773) — rotated OAuth refresh tokens now persist past the 6h window so `GROK_CREDENTIALS` doesn't silently expire mid-run.
- **AGENTS.md → full CLAUDE.md mirror** (#770) — every harness now loads a single, complete instruction set per run. No more partial context.
- **Run banner shows the resolved harness model** (#769) — not the config-default. You see what actually ran.
- **Per-skill model picker tracks active harness** (#766) — dashboard stays in sync when you switch harnesses.
- **`ci(okf)`: trigger only on markdown changes under OKF roots** (#777) — OKF check no longer fires on code-only pushes.
- **Rename `MCP_SECRETS_PAT` → `GH_SECRETS_PAT`** (#774) — standardized secret name across MCP and Grok paths.
- **Rename `BASESCAN_KEY` → `BASESCAN_API_KEY`** (#760) — consistent naming for the Base explorer key.
- **next 16.2.10 → 16.2.11** (#759) — high-severity CVEs cleared in the dashboard.
- Docs and sync PRs: six-harness setup in README + aeon.yml (#767, #768, #772, #763, #762).

## MiroShark: x402aff kit v0.1.1 — 14 PRs
