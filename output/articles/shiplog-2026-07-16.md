## MCP OAuth: one-click and durable

The big code ship this window: durable OAuth connect for MCP servers (#730–#733).

Four PRs in a block:
- `feat(mcp): durable OAuth connect for OAuth-gated MCP servers` (#730) — the base infrastructure
- `feat(mcp): enable one-click OAuth Connect for glim` (#731) — first integration live
- `Make MCP OAuth refresh durable for rotating-token providers` (#732) — rotating-token handling
- `docs(mcp-catalog): record Robinhood OAuth mechanics + why no offline_access` (#733) — Robinhood MCP catalogued, with notes on why `offline_access` isn't available

The pattern: wire the plumbing once, then skills can auth to any OAuth-gated MCP server without re-prompting. Token refresh is now durable. Robinhood in the catalog is notable — the framework is already looking at brokerage integrations.

## Grok 4.5 live

PR #725: `feat(grok): support Grok 4.5 + migrate deprecated x_search model to grok-4.3`

Two changes in one:
1. Grok 4.5 added to the model picker
2. The deprecated x_search model migrated forward to grok-4.3

Companion cleanup (#728): suppressed benign harness log notices from Grok, dropped grok-build from the picker (dead weight).

The operator posted "Grok 4.5 is live on aeon" and separately @aeonframework announced it — 21 likes, 3 reposts, 5 replies.
