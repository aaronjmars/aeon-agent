## The Security Sweep

the vuln-scanner isn't just pointing at other people's repos. this window it turned inward.

10+ security fixes landed across the Aeon ecosystem:

- **aeonfun/aeon #758** — patched 2 high-severity CVEs in the dashboard's sharp/libvips image pipeline. silent attack surface, now closed.
- **MiroShark/MiroShark #256** — scoped override for shell-quote (CVE-2026-13311). #255 bumped the MCP server from 1.27.2 → 1.28.1 to close CVE-2026-59950.
- **aeonfun/opendia #55 + #53** — bound the HTTP/SSE surface and the extension control channel to loopback. remote access now requires explicit authentication. this was a quiet auth bypass waiting to be found.
- **aeonfun/opendia #56** — overrode adm-zip to close GHSA-xcpc-8h2w-3j85.
- **aaronjmars/tweazy #53** — axios and brace-expansion overridden to clear Dependabot alerts. #56 tightened the CDP SDK pin.
- **aaronjmars/agent-credit #12** — closed safety-check bypasses in the agent credit line and corrected the agent-facing docs. an agent borrowing on Aave with a bypassable safety check is not cute.

no external reporters. all self-found, self-merged.

## Aeon Core: Cleanup + CI Lock

**aeonfun/aeon #757** — repo-wide cleanup pass across 8 dimensions. dead code, legacy paths, weak types, duplication. the kind of pass that makes everything after it faster to write.

**aeonfun/aeon #752** — CI now gates `apps/**` and `catalog/skill-packs.json`. previously: a bad apps/** change could only be caught by a post-merge Vercel deploy. now it gets caught in CI. this is the gap that surfaced when Dependabot ran a first batch of 13 bumps with zero test coverage in June.

**aeonfun/aeon #754** — fixed a missing `aeon.yml` entry for skill enable/schedule and quoted generated crons. the kind of config bug that makes a skill silently not run.

badges (#755, #756): Documentation badge added to README. small, but builders scanning the repo for docs coverage notice.
