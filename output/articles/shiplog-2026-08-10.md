# Agent Skills Spec Replaces OKF, Hook Fees Become a Buyback

**Window: 2026-07-27 → 2026-08-10** (two-week window — shiplog was stuck through the Aug 2–4 Actions outage, so this covers everything since the last real run)
**By the numbers: 100 PRs by @aaronjmars across all repos (search capped at 100 — real total may be higher) · aeonfun/aeon 87 commits / 82 merged PRs (44 operator + 38 others) · aeonfun/aeon 640 ⭐ (+63) · MiroShark/MiroShark 1429 ⭐ (+14)**

## The core: aeonfun/aeon — 44 PRs, 87 commits, 82 merged total

The headline is architectural: **Aeon dropped OKF and adopted the Agent Skills spec form globally** (#824). Every `SKILL.md` in the catalog moves to the emerging standard instead of the homegrown format — less to maintain, easier for outside contributors to read cold.

Riding alongside:

- **Secrets hardening** (#819) — `ALL_SECRETS` now builds from an explicit allowlist instead of `toJSON(secrets)`. The old approach could leak any repo secret into a skill's env by accident; the allowlist makes exposure opt-in per skill.
- **OpenTelemetry on the Node entry points + non-Claude harnesses** (#821), plus an epoch-format fix for `otel-cli` (#823) — traces now cover more than just the Claude Code path.
- **5 new skills in one PR** (#860) — `spend-watch`, `competitor-monitor`, `higgsfield`, `remotion`, `weekly-aeoncard`.
- **`pack-submit`** (#831) — publish a local skill as a community pack, the other half of the fork-and-share loop.
- **`aeon-update`** (#832) — a downstream framework updater, so forks can pull upstream changes without a manual diff.
- **Mine Claude Code history for skills to automate** (#820) — the `aeon` skill now looks at your own usage history to propose new skills.
- **memory-flush rework** (#828) — stamped consolidation dates, an adaptive window, dedup, and log rotation.
- **Persistence-contract corrections** (#816, #817, #818) — read-only MCP skills route output through `output/`, not `memory/` writes; docs now say so correctly, and `finance-district-mcp` got its `onchain_writes` declaration + a `notify -f` fix.
- **README rebuilt top to bottom** (#833–#859, ~25 PRs) — animated SVG hero, pill nav, "Proof of work" banner, a "heals-itself loop" diagram, a comparison table against Claude Code / Hermes / OpenClaw, and the skill count expressed as a stable "60+" floor instead of a number that drifted every sync.
- **Ecosystem catalog cleanup** (#814) — dropped NoelClaw and SyntheticsAI from the logos.

82 PRs merged into aeonfun/aeon this window; 44 were @aaronjmars's — the other 38 came from other contributors and automation, real signal that the repo isn't a one-person loop.
