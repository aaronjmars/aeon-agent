# Aeon shiplog — Aug 31 → Sep 14

Window: 2026-08-31 → 2026-09-14 (14 days — the last run was 08-31, so this covers two weeks). Everything below traces to a PR number, a commit, a measured count, or a linked post.

## The flagship: aeonfun/aeon — 53 PRs merged, 3 of them from outside contributors

54 commits, 53 merged PRs. Split: 22 by the operator, 13 dependabot, and **18 from three external contributors** — the ecosystem-growth number that matters most:

- **Svector-anu** (15 merged PRs) — the repeat contributor kept hardening the vuln-scanner: bounded the trufflehog filesystem scan ([#1054](https://github.com/aeonfun/aeon/pull/1054)) and the git-history scan ([#1030](https://github.com/aeonfun/aeon/pull/1030)) so it stops phantom-succeeding or hanging, shipped a new "Riva" research kernel for the scanner ([#1039](https://github.com/aeonfun/aeon/pull/1039)), and fixed four separate reliability-signal integrity bugs across skill-health, fleet-scorecard, chain-runner and notify ([#1017](https://github.com/aeonfun/aeon/pull/1017)–[#1020](https://github.com/aeonfun/aeon/pull/1020)) plus dev-loop review receipts ([#1027](https://github.com/aeonfun/aeon/pull/1027)).
- **NurstarK** (new contributor) — shipped a whole new skill from scratch: `miroshark-matchday`, weekly bulk football matchday sims + video handoff ([#1056](https://github.com/aeonfun/aeon/pull/1056)). First-time external contributor, first PR is a full skill, not a fix.
- **alexverify** — hardened the MCP server with optional runtime hardening docs ([#1001](https://github.com/aeonfun/aeon/pull/1001)) and bumped the eyebrow skill-integrity gate to v0.4.2 ([#1002](https://github.com/aeonfun/aeon/pull/1002)).

Operator-side reliability work: the read-only sandbox stopped losing `memory/logs` writes ([#1042](https://github.com/aeonfun/aeon/pull/1042)), `aeon-update` sync PRs stopped going CI-red on eyebrow version drift ([#1037](https://github.com/aeonfun/aeon/pull/1037)), egress's iron-proxy stopped MITM-breaking artifact uploads ([#1038](https://github.com/aeonfun/aeon/pull/1038)), email delivery now preflights for bounces before sending ([#1033](https://github.com/aeonfun/aeon/pull/1033)), and the scheduler now correctly reads per-skill model overrides from block-style `aeon.yml` entries ([#1024](https://github.com/aeonfun/aeon/pull/1024)). Plus one new skill: `compute-resell`, multi-provider compute reselling on Surplus ([#1036](https://github.com/aeonfun/aeon/pull/1036)).

## Headline: the Hook Marketplace went fully live

`aeonfun/univ4-hooks` merged 11 PRs this window, all building toward one thing: **create → audit → submit → list**, end to end, for Uniswap v4 hooks. The marketplace publish flow got ported to canon on aeonfun/aeon itself ([#1040](https://github.com/aeonfun/aeon/pull/1040)), a mandatory 10 bps AeonFee got enforced on every deployed hook ([#1035](https://github.com/aeonfun/aeon/pull/1035)), sc-audit reports went public for all 12 fleet hooks with bidirectional links back to each hook ([#17](https://github.com/aeonfun/univ4-hooks/pull/17), [#18](https://github.com/aeonfun/univ4-hooks/pull/18)), and HeavierHand + CapGate got redeployed across 7 chains with pool-price anchoring fixes ([#13](https://github.com/aeonfun/univ4-hooks/pull/13), [#14](https://github.com/aeonfun/univ4-hooks/pull/14)). On 09-12 a new "Submit Hook" skill shipped so any hook creator's own agent can submit straight to the marketplace — the platform stopped being aeon's fleet-only and opened up to outside hook builders.
