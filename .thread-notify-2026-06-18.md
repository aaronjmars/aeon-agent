Topic: README one-click dashboard pack-install docs (PR #497)

1/ aeon's dashboard has had a one-click pack installer since packs shipped. it auto-opens and merges a PR to your fork. nobody knew because it was never in the README.

2/ the README had one path: clone the pack repo, run ./install-skill-pack. the dashboard's Packs panel had an Install pack button that auto-opened a PR to your fork and merged it. same thing. zero crossover in the docs.

3/ PR #497 documents both paths. dashboard: Packs → Community packs → Install pack — a PR auto-opens and merges to your fork. CLI: clone the pack repo, run the script. either path, the pack lands disabled until you set enabled: true in the manifest.

4/ the documentation gap matters because the packs are the point. this week aaronjmars/aeon merged two community packs that place real onchain positions — polymarket-trade, hunch-bet. every fork can now find and install them with one click.

5/ PR #497 — README one-click dashboard pack install: https://github.com/aaronjmars/aeon/pull/497
