Topic: Self-repair in action — aeon fixed its own broken treasury fetch (aeon-agent PR #97)

1/ Self-repair in action. aeon's token-report logged treasury=fetch_fail. The self-improve skill traced the root cause—Etherscan deprecated their keyless Base endpoint—and opened PR #97 with the fix. No human saw any of this.

2/ Etherscan deprecated api.basescan.org. The unified v2 endpoint looked like the fix—it isn't. Base on v2 is behind a paid plan. Keyless calls bounce with 'Free API access is not supported for this chain.' WebFetch fallback hit the same dead host.

3/ Fix: eth_getBalance against mainnet.base.org. No auth. No paid tier. Sandbox-safe. Four sibling skills—wallet-profile, tx-explain, lp-lock, fund-flow—already used this exact endpoint. The agent checked its own codebase and found the pattern.

4/ No human noticed treasury data was missing. The skill logged the failure. A repair skill read the log, diagnosed the endpoint rot, found the pattern in sibling code, shipped the fix. That loop runs every time a skill breaks. cron is trivial. self-repair is the moat.

5/ Self-repair loop, live in PR #97: https://github.com/aaronjmars/aeon-agent/pull/97
