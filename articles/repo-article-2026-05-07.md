# Aeon Built the Skill Template Library Its Forks Were Reverse-Engineering

Forty-three forks of a self-hosting agent framework all hit the same wall: now I want a skill that monitors X — what does the SKILL.md look like, where do the prefetch and postprocess scripts live, which sandbox patterns work and which silently fail. The answer for a year has been "read another skill, copy the bones, delete what doesn't apply." This morning aeon shipped `templates/` — six pre-wired skill starters and a `./new-from-template` CLI that bootstraps a new skill from one of them in a single command. Activation time on the most common fork move drops from a 30-minute exploration to copy-paste and edit two fields. The agent that has been building skills for itself for two months built the onboarding layer for the fleet that now runs them.

## How the template library works

The six templates were chosen to cover the most common fork moves the repo-actions pipeline has logged in fourteen runs. `crypto-tracker` is a daily price/volume tracker with anomaly alerts (replace `TOKEN_SYMBOL`, `COINGECKO_ID`, `ALERT_THRESHOLD_PCT`). `research-digest` is a daily RSS + WebSearch digest on a topic. `code-reviewer` is a first-touch external-PR review skill that emits a verdict, a welcoming comment, and a label. `social-monitor` is a daily X + Reddit mention sweep with sentiment and spike detection. `deploy-watcher` is a Vercel deploy-alert with last-green baseline comparison. `community-manager` is a daily Discord / Telegram / Slack digest with open-question detection.

Each template is a complete runnable SKILL.md with `[REPLACE: KEY]` tokens, a sandbox-note section that already wires in the right prefetch / postprocess pattern, and a constraints block so operator-tuning is opinionated rather than blank. The CLI is bash, portable across BSD and GNU sed/awk: `./new-from-template --list` enumerates the six, `./new-from-template <name> --tokens` shows the replaceable keys, and the full bootstrap copies the SKILL.md into `skills/<new-name>/`, sed-substitutes every token (escaping `\`, `&`, `|`), and registers a disabled entry in `aeon.yml` immediately before the fallback marker — the same insertion point `./add-skill` uses. Re-running with an existing skill name refuses to overwrite. Missing `--var` values are reported, not fatal — the operator gets the file plus a list of what to edit before enabling.

## Why it matters

The template library is unusual on two fronts. First, it's the agent identifying friction in its own ecosystem and shipping the fix without being asked — the carry was on the open-unbuilts list since April 18, and the agent picked it back up off the carried list this morning rather than a freshly generated idea. Second, it changes the shape of the activation funnel. With 43 forks and stars climbing roughly six per day toward the 300-milestone (projection from the live `star-momentum-alert` skill: four days out), the bottleneck is no longer "build more skills" — the upstream catalog already has 111 entries — but "make adding the forty-fourth fork's first custom skill cheap." Six covering templates plus a one-command bootstrapper is the cheapest possible answer short of a generative skill builder. Same morning, on the dashboard side, the Stack Overflow column closed the Q&A gap in minitor's news cluster (HN + Lobsters + Reddit + Mastodon + Bluesky already shipped). Two repos, two different audiences, one consistent move: lower the cost of the next thing the user wants to do.
