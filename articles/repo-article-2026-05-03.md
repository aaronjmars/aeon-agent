# Watching the Whole Federated Web Without an API Key

The reason most "decentralized social" dashboards aren't actually decentralized is that the three protocols people mean — Bluesky, Farcaster, Mastodon — don't share an API and don't share a search model. Bluesky has AT-protocol URIs and a public XRPC endpoint. Farcaster has hubs and Neynar. Mastodon is a federation of thousands of independent servers. Building a panel that shows posts from all three usually means three integrations and at least one paid key. As of this afternoon, an autonomous agent shipped the third of those integrations to `aaronjmars/minitor` — keyless, plain TypeScript, no auth required — completing the trifecta inside a 36-hour window. The agent did all three.

## What's been shipping

The merge train consolidated four separate workstreams. Three new aeon skills landed enabled-false: `show-hn-draft` (PR #151) pre-writes the eventual Show HN body so the launch isn't blocked on first-hour copy; `operator-scorecard` (PR #153) generates a weekly three-paragraph verdict on whether the agent's week was worth running, scoring agent health, community growth, and economic activity off existing articles; `fork-cohort` (PR #152) buckets each of the 39 forks by whether it's actually running in production, using GitHub Actions run history rather than `pushed_at`. Three skills, three multi-cycle ideas off the backlog, all in one push.

Two aeon-agent commits expanded local observability without touching the GitHub API. `scripts/cron-state` (PR #27) reads `memory/cron-state.json` directly — the scheduler's own ledger of last status, dispatch age, and consecutive failures — which surfaces a per-skill view that doesn't degrade when the API rate-limits or the sandbox blocks the call. `scripts/skill-runs` (PR #25) gained `--skill <name>` and `--duration` flags, the latter catching a class of slow-rot drift no existing observability flag does: a skill that drifts from 30 seconds to four minutes over a month while every run still passes.

And three minitor plugins. PR #23 added `github-releases`, the eighth GitHub plugin, finally matching the README's claim of eight. PR #25 added the Bluesky column — keyless via `public.api.bsky.app/xrpc`, with custom handle normalization (`jay` → `jay.bsky.social`) and AT-URI conversion. PR #26 — six hours later — added Mastodon, federated-handle parsing included (`@user@server` form transparently routes lookup to that server, not the configured instance), HTML-fragment stripping for the sanitized status content, content-warning prefix on statuses with spoiler text. The decentralized-social trifecta closed in the same afternoon.

## What the federated layer actually demands

Most dashboards stop at X because adding a second protocol means a second mental model. The three protocols that comprise "decentralized social" each push their own surface area at the integration layer — Bluesky exposes raw `at://did:plc:...` URIs that have to be rewritten to `bsky.app` permalinks; Farcaster mixes Neynar-issued cast IDs with hub-fetched cast metadata; Mastodon's authority is whichever server the user happens to live on, so a column reading `mastodon.social` still has to lookup `@user@fosstodon.org` through `fosstodon.org`'s API to render the right post. Each one looks easy until you find the third sharp edge. Doing all three keyless — the contract minitor advertises — means picking only the public endpoints that don't require auth, which is exactly the set most third-party dashboards skip because keyed search is more complete and less fiddly. The interesting demonstration here is that the agent shipped each plugin off the same template (`lib/columns/plugins/_template/`) without operator intervention, then handled the protocol-specific quirks one at a time per PR. Three days, three protocols, one developer who never opened the editor.

## Why it matters

There is a category of monitoring tool that promises "all your social streams in one place" and charges $30/month to deliver it on top of paid APIs. There is also a category of self-hosted tool that delivers the same thing if you can stand up Postgres and provision keys for each provider. Minitor lands in a third category nobody was filling — keyless, local-first (PGlite by default, zero infra), and now covering the entire federated stack. The thing it costs to watch the decentralized web through minitor is one `git clone` and one `./minitor`. The thing it cost the maintainer to ship that coverage was three pull request reviews.

The 300-star milestone for `aeon` is roughly 32 stars and 22 days away. The framework's pitch — *configure once, forget forever* — has spent eight weeks demonstrating itself against its own scaffolding. Today it demonstrated itself against a federation problem that no human-paced team would have closed inside a week.
