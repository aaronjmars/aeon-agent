## What Shipped

### The Fork-Intelligence Layer Reached Five Skills On Both Sides Of The Upstream

Last week's shiplog called the fork-intel layer a 3-skill stack with composable state files. This week it became a **5-skill stack with parity across upstream and aeon-agent**. On aeon: `fork-skill-gap` (PR #176, May 16 — weekly Sunday 21:00 UTC, diffs each POWER+ACTIVE fork's `skills.json` against upstream and reports per-fork missing-slug counts plus a top-10 inverse rollup of upstream skills the fleet hasn't adopted) and `fork-first-run-alert` (PR #179, May 17 — daily 20:30 UTC, names every fork's first workflow-run completion same-day with count-driven notify policy capping noise on viral activation days). Both `enabled: false`, both chain off `fork-cohort-state.json` when fresh (≤8 days) and fall back to live `gh api repos/{parent}/forks --paginate` when the cache is missing — so they work day-one before `fork-cohort` is enabled. On aeon-agent: verbatim backports of both landed in the same merge wave today (PR #52 + PR #50, 9th and 8th in the same-day-after backport sequence that started May 3). The five skills now answer five orthogonal questions about every fork: alive? shipped? who's pushing code? what hasn't been adopted from upstream? when did it activate?

### The Sandbox-Marker Contract Closed Around Every XAI Consumer

A four-PR pattern that started May 10 finished this week. PR #37 introduced the `.error` marker contract for `tweet-allocator` (sandbox-blocked Bankr API → typed marker file → skill reads the marker instead of mis-attributing failure). PR #43 (May 14) extended `.truncated` marker handling to `narrative-tracker`, `remix-tweets`, and `tweet-roundup`. PR #48 (merged May 17/18) fixed `token-report`'s 5-day false-positive "XAI_API_KEY not set" line by reading the fetch-tweets log instead of curling XAI directly. PR #51 (May 19) closed the contract: `refresh-x` — the last enabled-eligible XAI consumer still on direct-curl — was rewired through a four-path ladder (prefetch cache → error short-circuit → truncated marker → local-mode direct-curl fallback → WebSearch). The pattern is now codified: sandbox-blocked auth steps write typed markers; downstream skills read the markers rather than re-curling. The same shape applies to `.bankr-cache` and is the canonical sandbox-fallback in this codebase.

### Two Launches Got Asset-Pack Coverage, Plus A Column To Watch Them With

`product-hunt-launch` shipped on aeon May 15 (PR #175) — workflow_dispatch one-shot that drafts the full PH asset pack from live repo state, with a banned-marketing-words list (`AI-powered`, `revolutionary`, `leverages`, `powerful`, `framework`) trained on what PH treats as obvious AI-generated copy. Same input set as `show-hn-draft` so HN and PH launches stay coherent. Backported verbatim to aeon-agent May 17/18 (PR #49). Then minitor closed the loop on May 17/18 with PR #42 — the 44th column type, a keyless Product Hunt RSS column. The "monitor the launch I'm about to do" use case is now self-served: when aeon's PH submission goes live, the operator pins `PH · ai-agents` next to `HN · top` in the same dashboard view.

## Fixes & Improvements

- **scan.sh empty-array crash on Bash 3.2 macOS** (aeon #186, May 19): silent first-touch failure for every macOS operator running `./add-skill` — `set -euo pipefail` + empty `"${arr[@]}"` aborts on Apple's holdout `/bin/bash` 3.2. Wrapped three print loops in `[[ ${#arr[@]} -gt 0 ]]` guards mirroring the JSON-path pattern already in place. Unblocked the 14 new macOS forks that arrived in the last 24h alone.
- **Dashboard multi-remote `gh` ambiguity** (aeon #169 + #178, May 14 + May 17): `gh` CLI multi-remote ambiguity broke auth, secrets, analytics, and run-logs routes whenever a fork added upstream as a second remote (recommended in the README). Six API routes converged on `execFileSync` + `-R repo` argv arrays. Removed the last shell-interpolation surface in the dashboard.
- **Bankr-gateway prop wire-through** (aeon #171, May 14): an April commit had been silently typecheck-failing on `main` for weeks. `gateway` state existed in `page.tsx` but never reached `TopBar` or `SkillDetail`.
- **Catalog hygiene cross-surface** (aeon #173 + #174, May 15): 117-skill count now consistent across `skills/`, `skills.json`, `aeon.yml` cron lines, README hero, project-structure tree, category table, and `skill.jpg`. Three previously unreachable skills (aixbt-pulse, schedule-ads, create-campaign) got their cron line so they can actually fire.
