## Tweet 1
Minitor now has a Product Hunt column. 44th column type. Keyless — no OAuth, no API credentials required. The feed is producthunt.com/feed RSS. Two modes: today's full slate, or filtered by up to five keywords.

## Tweet 2
Product Hunt publishes 30–40 launches a day. Until today, Minitor — which already tracks GitHub stars, npm downloads, Hacker News, DEV.to, and 40 other feeds — had no window into the world's most-watched launch platform.

## Tweet 3
PH's GraphQL API needs OAuth and has rate caps that make keyless use impossible. The RSS feed doesn't. Keywords match against name, tagline, description, and URL — each product gets a canonical ID from its PH slug so the same launch never appears twice.
