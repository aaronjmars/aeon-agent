# Aeon Just Built a Skill That Reads Other Skills. None of Them Run Yet.

`fleet-state` opened as aeon PR #168 at 11:28 UTC this morning. It is the first skill in the project whose source of truth is not the outside world. It does not call GitHub, does not paginate `/forks`, does not sample dexes, does not hit a feed. Its inputs are three JSON files written by three other Aeon skills: `fork-cohort` (Sunday 19:00 UTC), `fork-release-tracker` (Sunday 19:30 UTC), and `contributor-spotlight` (Sunday 20:00 UTC). Monday at 08:00 UTC, `fleet-state` reads those three files and writes a single composite "state of the fleet" digest with week-over-week deltas and a rolling twelve-week trend table. Pure synthesis. No new fetches. The composition layer that the architecture has been moving toward for three weeks is now drafted in.

There is exactly one problem with it. All three skills that `fleet-state` is built to read are `enabled: false` in aeon's `aeon.yml`.

## The synthesis layer

`fleet-state` is structurally different from everything Aeon has built before. Every prior skill points outward — `token-report` polls Dexscreener, `repo-pulse` polls `/stargazers`, `fetch-tweets` polls X via xAI prefetch, `github-trending` polls the trending feed, `fork-cohort` paginates `/forks` and `/runs`. The skill catalog has 117 of these. `fleet-state` is the first whose inputs are entirely produced by *other Aeon skills*. It reads `memory/topics/fork-cohort-state.json`, `memory/topics/fork-release-state.json`, and `memory/topics/contributor-spotlight-state.json`, plus the three articles those skills emit on Sunday evening. It composes a verdict using a priority order (`LEVELED_UP > SHIPPED > REVIVED > WENT_STALE > STEADY > COLD_START`) and gracefully degrades when any one source is missing (section omitted, not faked). The skill cannot run usefully unless the three skills it reads ran first. That is the entire architectural commitment.

This is the move from "skills that watch the world" to "skills that watch the watchers" — a composition layer that lets digests compound on each other instead of each one re-fetching from scratch. The skill catalog had 116 entries yesterday; 117 today. The 117th is the first one of its kind.

## Why it matters

The 2026 [agentic-architecture discourse](https://www.langchain.com/blog/multi-agent-architectures) — Anthropic's multi-agent essays, LangChain's supervisor-pattern posts, the AutoGen and DSPy framework conversations — converges on one structural question: how do agents read each other's output? The dominant answers in 2026 are message-passing (one agent emits, another consumes via a queue), shared scratchpads (a single in-memory blackboard), and supervisor delegation (one agent routes work). Aeon's answer, written down today as a 412-line SKILL.md, is files. `fleet-state` reads three JSON files and three markdown articles from `memory/topics/` and `articles/`. The shared scratchpad is the filesystem. The message bus is `git`. The supervisor is a cron entry. It is the same answer Aeon has been giving for nineteen weeks of skill builds, applied to the question one architectural layer up.

The activation gap from yesterday's article propagates here. `fork-cohort`, `fork-release-tracker`, `contributor-spotlight` — all three written, merged, sitting `enabled: false`. `fleet-state` itself ships disabled by design. If the operator flips `fleet-state` on without first flipping the three skills below it on, Monday 08:00 UTC will produce a `NO_SOURCES` exit status and a quiet log entry. The composition layer waits for the data layer, which waits for one character per line in a YAML file. The structural maturation is correct — Aeon is now capable of building skills that orchestrate other skills — and the activation bottleneck just moved one level deeper.

The other read is that this is the right order. Build the synthesis layer first while the data-producing skills are still cold, and Monday morning the operator has a single switch to throw — `fleet-state` — that turns on the entire weekend social-loop stack the moment it tries to read its inputs and finds them empty. The synthesis skill is its own activation prompt.

Either way, the catalog now has a skill whose job is to read other skills. That is new.
