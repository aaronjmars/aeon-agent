# Week in Review: Pack Pipeline Ships; Six External Contributors Fill It

*2026-06-22 — Weekly shipping update*

> Aeon's community skill-pack infrastructure closed end-to-end this week — one-click install, zero-touch auto-merge, fork isolation, contributor validation — and six external builders shipped skills through the new pipeline in the same week it went live.

## What Shipped

### The install arc closed: registry to auto-merged PR in one click

The full pack install flow shipped across a week of commits. `feat: first-party skill-pack system` (#474, 9bd9ed7) defined the schema — Core skills always on, community packs as opt-in groups. `feat(dashboard): one-click community pack install + "add more" packs button` (#483, da0a970) put the install button in the dashboard UI. `feat(install-skill): zero-touch auto-merge + ensure Actions can open PRs` (#485, afd4efe) wired the merge so a PR closes without operator intervention. `feat(dashboard): installed community skills get their own always-visible "Installed" pack` (#486, 078eee1) surfaced the result. `fix(dashboard): scope enabled-packs to the repo so forks start Core-only` (#491, fbdcd0e) sealed fork isolation — new clones don't inherit a prior operator's community pack choices. `feat: add scripts/validate-pack.sh local pre-flight validator` (#495, a2947c2) rounded it out: contributors validate pack structure locally before opening a PR. Browse, install, auto-merged.

### Six external contributors ship skills in one week

Before the week was out, six external builders had shipped through the pipeline. Raj Karia merged Hunch, a prediction market trading skill (#472, fe8579f). Misha Kolesnik added glim.sh, a live-data MCP with x402 and per-request micropayments (#470, 271f195). Claw Hunter landed a general automation skill pack (#498, 7bd1b8d). logbookbase contributed logbook (#507, 9a97ae9), a signed hash-chained action receipt skill that logs every agent action to a verifiable chain. Six contributors, six different capabilities, same week the install pipeline closed.

### Both gateway surfaces ship their first documentation

The A2A server and MCP server have been live for months without a quickstart for the builder trying to wire them up. Both shipped their first READMEs this week. `docs(a2a-server): add README quickstart for the A2A gateway` (#501, ab15246) landed on 06-19 — 127 lines added to `apps/a2a-server/README.md` covering how skills expose as A2A tasks, the task lifecycle, and client code examples. `docs: add apps/mcp-server/README.md with quickstart and Claude Desktop config` (#512, 25d2544) followed on 06-21 — 99 lines covering `./add-mcp` flags, the `aeon-<slug>` tool naming contract, a Claude Desktop JSON snippet, and a `test_connection.py` round-trip. Two integration surfaces, both now copy-paste-ready.
