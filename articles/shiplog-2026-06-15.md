# Week in Review: Aeon Cut Its Last Vendor Lock and Rebuilt the On-Ramp

*2026-06-15 — Weekly shipping update*

> Aeon stopped requiring an Anthropic key to run, rebuilt the clone-to-first-run path around time-to-first-launch, and watched six outside contributors merge onchain skills into the registry.

## What Shipped

### Run Aeon on whatever LLM key you already have
The single biggest fork blocker — "I don't have an Anthropic subscription" — is gone. `feat(gateway): add OpenRouter, UsePod, Venice & Surplus LLM gateways` (#409) widened the provider list, and `feat(gateway): resolve LLM provider at run time from which secrets are set` (#430) made the choice automatic: Aeon now reads whichever keys are present and routes accordingly, touching 15 files from `.github/workflows/aeon.yml` to the dashboard auth modal (+95 / −36). `feat(gateway): cascade failover across providers on any failure` (#435) means one provider going down no longer halts a run — `scripts/llm-gateway.sh` falls through to the next configured gateway (+79 / −24). Bankr `bk_` keys auto-route through the Bankr gateway (#386), and by week's end `refactor: single gateway-provider registry` (#469) collapsed the scattered routing logic into one source of truth. The upshot: a forker brings the key they have, not the key Aeon used to demand.

### The clone-to-first-run path got rebuilt
Onboarding friction is a priority-zero bug, and this week went straight at it. The README was reworked for time-to-first-launch with a cross-platform quick start, a fork walkthrough, and a run-without-push path (#396, #398, #402). `feat(dashboard): add "Connect with Claude Code"` (#433, #434) put one-click OAuth on the Settings tab. The config dashboard now shows exactly which API key and which MCP server each skill needs, with clickable links to get them (#385, #393, #395), and `fix(dashboard): gate skill runs on provider key` (#459) makes a misconfigured fork fail loud instead of silently doing nothing. First-time contributors finally have a `CONTRIBUTING.md` anchored to the real skill/gateway/CI conventions (#465) plus bug-report and feature-request issue templates (#466). And the SOUL.md and STRATEGY.md tabs with their builder skills (#448, #451) let a forker make the instance theirs — voice and north-star — without hand-editing files.

### Outside contributors are shipping onchain skills
The ecosystem-growth number moved in public this week: six external contributors merged. The headline is `beamr-route` (#419, by SahilParikh03) — pay-per-call LLM inference over x402 with an onchain receipt, a brand-new skill plus `scripts/beamr-pay.mjs` (+154 lines). Dax landed CTRL, on-chain automation on Base (#353). Three external skill packs entered the registry — signa's 20-skill update with spend mandates and x402 receipts (#355), Mneme (#356), and Careful Finance (#357) — and ashneil12 added a `VENICE_BASE_URL` override for the Venice sidecar (#460). That is forks and contributors turning into merged code, not just stars.

## What's Nearly Here
One open PR remains: `feat(gateway): add BEAMR as an LLM gateway` (#418, SahilParikh03) — a second x402 inference path alongside the merged `beamr-route` skill. It's been idle since 2026-06-12 and is awaiting review, not blocked on anything new.
