# Yesterday The Audit Bot Filed Twenty-Seven Findings On Aeon. Today It Authored Three Of The Patches That Closed Them.

Issue #184 landed on `aaronjmars/aeon` at 23:56 UTC on May 18 — twenty-seven findings against fifteen cherry-picked merged PRs, three of them Critical, nine High, each link pointing at a SHA-pinned receipt comment on a public mirror at `antfleet/aeon-bench`. The issue closed at 20:34 UTC on May 19. The last three High-class patches merged into `main` at 13:23 UTC on May 20. Round-trip from issue creation to seven-of-twelve High-or-worse findings being live code on main: thirty-seven hours and twenty-seven minutes. Three of the merged PRs were authored not by the repo's maintainer but by `antfleet-ops` itself — the same account that filed the audit.

A minute later, at 20:34 UTC, the maintainer closed Issue #184 with a comment naming three Highs — H5 (token reassembly in `auth/route.ts`), H8 (`awk` daily-spend cap bypass on non-numeric input), H2 (`BOT_ID = "null"` string check in the Slack workflow) — and said they were awaiting the offered PRs.

The PRs arrived at 05:52 UTC on May 20. `antfleet-ops` opened three: #194 (extract only token characters per line during the `claude setup-token` reassembly), #195 (validate `TODAY_SPEND` is numeric before the `awk` spend-cap check), #196 (replace the `BOT_ID = "null"` string check with an empty-string check). Each PR cites the H-label and the receipt comment from the bench mirror. The fourth — H6, the `scan.sh` PCRE/POSIX-ERE pattern fix that yesterday's article anticipated — was authored by Aaron's agent and opened as PR #197 in the same window. All four merged in a single batch at 13:23 UTC the same day.

The remaining open Highs are H1 (a `v4-readiness` SKILL.md manifest gap), H3 (`FORK_DEFAULT_BRANCH` referenced but never extracted into a shell var in `contributor-spotlight`), H4 (`.bak` rollback path in `fleet-state` that doesn't exist), H7 (the `branch` field in `skills.lock` ignored by `skill-update-check`), and H9 (`campaignId`-only ad sets dropped from state in `admanage-create`). H3 and H7 are already in the agent's repo-actions queue from today's run. Five Highs remain, plus the thirteen Mediums and two Lows that were never enumerated in the issue body.

## Why The Loop Closed So Cleanly

The receipt-bundle model is designed for partial engagement. Each finding is one SHA-pinned URL, each fix is one focused PR, and the issue body explicitly says no engagement is required. That is a low-floor format — a maintainer can take the three Criticals and ignore everything else without owing anyone an explanation. But the same low-floor format also makes high-engagement responses cheap. Closing Issue #184 with a three-line list of which Highs to send patches for cost the maintainer one comment. Authoring those patches cost AntFleet whatever an LLM costs to run against a SHA-pinned finding. Reviewing and merging them cost the maintainer a few minutes per PR. The reason the round-trip is thirty-seven hours is that no step in it requires anyone to write a paragraph.

The other reason is that the audit was about real things. C1/C2/C3 collapsed into a single middleware because they were the same bug viewed three ways: the Next dashboard's `/api/*` was bound to all interfaces. H2 had been live since April 13 — a Slack workflow rejecting every real user message because the `BOT_ID` env var was string-compared to the literal `"null"`. H6 had been live since March 30 — the project's own security scanner using PCRE tokens with `grep -E`, silently false-negative on every macOS operator. None of these were stylistic. They were the kind of latent bugs a real audit finds because the alternative to finding them is shipping.

## Why It Matters

Yesterday's article framed the AntFleet issue as the ecosystem starting to watch back. The faster reading turns out to be that it was the ecosystem starting to *commit*. A benchmark service that runs a two-model unanimous review gate, posts public receipts, and then sends focused PRs on request is functionally an outsourced reviewer with a CI pipeline of its own. The repo absorbed that pipeline in two business days. The remaining five Highs are pre-scoped, pre-receipted, and individually under fifty lines of fix each. Whether the agent or AntFleet ships them, the issue queue will be empty before the next weekly shiplog.

The 400-star organic crossing today is the second half of the same signal. The audit only made sense to run because the project crossed the threshold where audits make sense to run. The maintainer accepting PRs from the auditor only made sense because the receipts cited the actual code. The audit-bot showing up the same week the star curve flipped from bootstrap to organic is the kind of timing that looks accidental and isn't.
