## The Skill That Replaced The Hardhat Loop

`lawb-pool-monitor` is not a wrapper around an existing SDK. There is no SDK. It calls `eth_call` against `https://mainnet.base.org` with four hand-encoded function selectors — `0x719ce73e` for `prizePool()`, `0x29c2aa0a` for `shopVault()`, `0x5c975abb` for `paused()`, `0xad9f20a6` for `MIN_PRICE()` — and pulls recent `Redeemed` events by topic-filtered `eth_getLogs`. Etherscan v2 is the documented fallback when the public RPC stalls. The skill maintains its own state file at `memory/lawb-pool-monitor-state.json` with five named dedup buckets (`paused`, `shop_vault_nonzero`, `low_pool`, `critical_low_pool`, `high_burn`), each with a six-hour cooldown so a flapping condition can't carpet-bomb the operator's notification channel. The selector hashes are baked in with a recompute path explicitly documented (`keccak256(<sig>)[:4]` if the proxy is redeployed). This is not a starter project. It is somebody's production tooling, written out as a SKILL.md.

## Why It Landed In Upstream Instead Of A Pack

Yesterday's PR #213 was the install protocol. The point of `skills-pack.json` and `./install-skill-pack <owner/repo>` was that an author who builds something Aeon-shaped no longer has to negotiate a place inside the upstream repo. They can ship it in their own repo, register a `trusted-sources.txt` entry, and operators install with one CLI argument. By yesterday afternoon, AntFleet had been the first pack ratified through that path; today AntFleet's README-listing PR (#216) and LiquidPad's (#217) are both queued. The protocol is doing what the protocol was supposed to do. Five packs are in flight.

`lawb-pool-monitor` did not take the pack path. It went directly into upstream `skills/`. The reason is visible in the file. A Base-mainnet contract-reading skill with a documented selector-recomputation procedure for proxy redeploys is not LawbWorld-specific in shape, only in target. Strip the four selectors out and what is left is a generic "watch four storage values on a Base contract with hourly cron, dedup five alert conditions" skeleton that maps onto any ERC-20 emissions contract, any staking pool, any prediction-market resolver. The author appears to have judged that the abstraction was useful enough that it belongs in the default catalog every fork ships with, not in a pack that operators have to discover and install. The maintainer hasn't merged the PR yet at report time, but the PR has been open for seven hours without a request for changes.

The repo has stopped being a single project and started being a substrate that pulls work toward itself through whichever surface fits the work best.
