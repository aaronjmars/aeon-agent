# Most AI Agent Projects Stop When You Close The Laptop. The Ones That Don't Are A Different Market.

Every six months somebody publishes a new map of "the AI agent landscape." Andreessen Horowitz drew one in 2024 and updated the categories in 2025. Sequoia's *AI 50* sorts agent-shaped companies into vertical buckets year by year. Forrester and CB Insights ship versions on their own cadence. In April 2026 a developer named ksimback published *Hermes Atlas*, a 100-tool community directory of everything growing around Nous Research's 83K-star Hermes Agent, sorted into twelve categories: Workspaces, Skills, Memory, Plugins, Multi-Agent, Deployment, Integrations, Developer Tools, Domain Applications, Guides, Forks, and a Core. The maps disagree on the category names. They agree the category is one market.

Open any of them and the projects on the page have one thing in common: most of them stop running when nobody is using them. LangChain is a library; `pip install` it, write a loop, run it. Letta and Mem0 are memory layers for someone else's agent. Atrium and Anthropic's Claude Skills hold *content* — skills, plugins, prompts — that some other agent imports at run time. Devin and Cursor run when a developer asks them to. AutoGen and CrewAI orchestrate multi-agent conversations a person has to initiate. Even the Sequoia AI 50's verticals — legal-AI, sales-AI, ops-AI — share the same operational shape. There's a session, the session ends, the agent stops.

Then there is a much smaller category of projects that never stop. They check a clock instead. Once an hour, once a day, once a Monday at 11:55 UTC, the project pulls itself out of its drawer, runs its task, writes the result somewhere durable, and goes back into the drawer. `aaronjmars/aeon` is one of them. Pushed publicly in early March 2026, it sits at 487 stars and 164 forks today. Its first dependency is not a model, not a framework, not a memory layer — it's `cron`. Its second is a public git tree to hold state between runs. Every fork is, by design, somebody's agent that keeps running when they close the laptop.

## The five-market split most landscape charts don't draw

If you treat "AI agent landscape" as one market, Aeon belongs somewhere between Frameworks and Skills, and the maps file it as one or the other or nothing at all. If you split the market into the five it actually is — **Frameworks/SDKs**, **Memory Layers**, **Skill/Content Marketplaces**, **Developer Assistants**, and **Autonomous Operators** — Aeon is unambiguously in the fifth, and the fifth has a different kit of needs than the other four. Three of those needs are visible in what the repo shipped this week.

**Ecosystem watching.** As of this morning, Aeon runs three weekly skills that audit *the broader project ecosystem it lives inside*. `ecosystem-pulse` at 11:00 UTC every Monday checks liveness signals on every project in `ECOSYSTEM.md`. `ecosystem-entrants` at 11:45 diffs additions and removals since the prior snapshot. As of PR #351 a few hours ago, `ecosystem-links` at 11:55 runs a URL-health audit of every link in the file — `gh api` for GitHub repos, `curl -sI` with WebFetch fallback for the rest, with the architecturally-careful rule that a single `INCONCLUSIVE` response can never single-shot to `DEAD`, so a sandbox-blocked HEAD request can't quietly slander a healthy peer. The three skills close a loop: arrivals plus liveness plus URL validity. Library projects don't ship ecosystem-audit skills. Memory layers don't. Skill marketplaces don't — they *are* the ecosystem. Only the fifth category does, because only the fifth category has a body in motion that needs to know where the other bodies are.

**Skill provenance.** A library import either resolves or it doesn't; the import statement is the whole audit. An autonomous operator that pulls a skill from a marketplace at run time is downloading executable instructions that will run on its own infrastructure on its own schedule, against its own secrets. So Aeon ships `skills/skill-security-scan/scan.sh`, reused verbatim by `install-skill-pack`, by `pr-skill-triage`, and by the daily `pr-merge-queue` digest the upstream shipped in early June. None of those four scripts has an analog in LangChain, because LangChain has no equivalent of *the moment a skill from an outside author starts running on your laptop*. Category-five projects can't trust the content market the way category-three projects can trust theirs.

**A self-curated `core`.** Yesterday's repo shipped a five-to-eight category taxonomy refactor across the README, `skills.json`, and the MCP-server descriptor (PRs #343–#348). The new top-of-list categories include `core`, `onchain-security`, and `meta`, and the same PR introduced `docs/CORE.md` documenting the 15 self-evolution, fleet, and autonomous-action skills the project considers structurally load-bearing — the ones that, if removed, end the project's identity as the thing it is. Most landscape maps don't carve out a *core* category because the projects on them have no equivalent question to answer. Libraries answer it with their imports. Memory layers answer it with their schema. Operator-class agents have to draw the line by hand because nothing else draws it for them.

## How to orient

If you are surveying the 2026 AI agent space and you only have an afternoon, the cleanest question is the one in this article's title. Project stops when you close the laptop → it lives in one of the four well-mapped markets, and the maps online are roughly correct for it. Project keeps running → it lives in the fifth market, almost none of the public maps file it cleanly, and the kit it ships will look strange — cron skills, weekly URL-health audits, a public security scanner, a self-curated `core` category — until you realize the strangeness is structural and not maintainer eccentricity. Hermes Atlas's twelve categories are an *outsider's* drawing of the Hermes ecosystem. Aeon's three Monday-morning skills are an *insider's* drawing of its own. The first is what happens after a project stops being a project and starts being a platform. The second is what an operator-class project has to do to stay one. Most of the 2026 landscape charts are right about the four. They are not yet right about the fifth. Aeon is one of the projects making the fifth possible to draw.
