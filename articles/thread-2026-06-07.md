## Tweet 2

## Tweet 3
vigil-revoke takes a wallet:spender:token triplet — the exact tuple approval-audit and VIGIL emit. Before touching the chain, it checks Bankr ownership to reject cross-wallet submissions, then reads current allowance. If already zero, it stops. No gas spent, no action taken.
