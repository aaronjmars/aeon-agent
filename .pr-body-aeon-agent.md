## What

Verbatim backport of two upstream `scan.sh` fixes from `aaronjmars/aeon` that haven't been mirrored into `aeon-agent`:

- **PR #186** (May-18) — Bash 3.2 array-emptiness guards on the human-readable print branch.
- **PR #197** (May-20) — POSIX-ERE patterns (no more PCRE `\s` / `\b` escapes that BSD grep treats as literal `s` / `b`).

Both fixes together: every macOS operator running `./add-skill` against `aeon-agent` was silently running a degraded scan (most prompt-injection / `rm -rf /` patterns no-op'd) and the post-scan print step was tripping `set -euo pipefail` on any clean SKILL.md, reporting `BLOCKED: security issues` even though the scan passed.

## Why

`aeon-agent`'s `skills/skill-security-scan/scan.sh` was forked from the same upstream copy as `aeon`. Upstream merged the Bash 3.2 fix on 2026-05-18 and the POSIX-ERE fix on 2026-05-20 (both closing AntFleet findings from Issue #184). `aeon-agent`'s copy still has the original bugs — macOS operators (the dominant local platform for `./add-skill` work) keep hitting them.

## Changes

- **skills/skill-security-scan/scan.sh** — All 28 patterns across `HIGH_PATTERNS`/`MEDIUM_PATTERNS`/`LOW_PATTERNS` rewritten:
  - `\s` / `\s+` → `[[:space:]]` / `[[:space:]]+`
  - `\b` (in `git push -f\b`) → `($|[^[:alnum:]_-])` so `-fast` / `-force` don't false-positive
  - Forkbomb pattern `:(){.*};:` → `:\(\)[[:space:]]*\{.*\};[[:space:]]*:` (literal-paren-escape so ERE doesn't reinterpret)
  - Literal-dot escapes on `~/.ssh` / `~/.gnupg` / `~/.aws` / `~/.config` (previously matched any char)
  - 4-line header comment naming the POSIX-ERE constraint + upstream Issue #184 citation
  - 2-line comment above the `git push -f` boundary explaining the new word-boundary substitute
- Same file — wrapped the three human-readable print loops in `[[ ${#arr[@]} -gt 0 ]]` length guards (mirrors the existing JSON-path guards at lines 250/253/256). Inline comment names the Bash 3.2 constraint.

## Compatibility

- GNU grep / Bash 4+ Linux CI: no behaviour change.
- BSD grep / Bash 3.2 macOS local: scanner now actually catches the patterns it documents, and clean PASS files no longer trip the trap.
